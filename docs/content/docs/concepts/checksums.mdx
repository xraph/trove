<Callout type="warn">
Trove doesn't compute or verify checksums on `Put` and `Get` yet. `trove.WithChecksumAlgorithm` stores an algorithm in the config, but nothing reads it, `trove.ErrChecksumMismatch` is declared but never returned, and there's no `X-Trove-Checksum` header. Where hashes are used today is content-addressable storage and the dedup middleware.
</Callout>

## Algorithms

Three hash algorithms show up across Trove:

| Algorithm | Checksum constant | CAS constant | Cryptographic |
|-----------|-------------------|--------------|:-------------:|
| SHA-256 | `trove.SHA256` | `cas.AlgSHA256` | Yes |
| BLAKE3 | `trove.Blake3` | `cas.AlgBlake3` | Yes |
| XXHash | `trove.XXHash` | `cas.AlgXXHash` | No |

## The Checksum Setting

You can set an algorithm when you open a Trove instance, and `DefaultConfig` picks SHA-256:

```go
t, err := trove.Open(drv,
    trove.WithChecksumAlgorithm(trove.Blake3),
)

cfg := trove.DefaultConfig()
// cfg.ChecksumAlgorithm == trove.SHA256
```

The value is kept in `t.Config()` and has no other effect today. `info.ETag` on a stored object is whatever the driver reports, not a Trove-computed hash.

The extension's metadata `Object` model has `ChecksumAlg` and `ChecksumVal` columns for when this lands, but nothing fills them yet.

## CAS Hash Format

Content-addressable storage names content by a prefixed hash that encodes the algorithm and the digest:

```
algorithm:hexdigest
```

Examples:

```
sha256:e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
blake3:af1349b9f5f9a1a6a0404dea36dcc9499bcb25c9adc112b7cc9a93cae41f3262
xxhash:ef46db3751d8e999
```

Pick the CAS algorithm with `trove.WithCAS(cas.AlgBlake3)` or `cas.WithAlgorithm`. See [Content-Addressable Storage](/docs/storage/cas).

## Verifying Content Yourself

The hashing helpers live in Trove's `internal` package, which code outside the module can't import. To check integrity end to end today, hash the bytes on your side with `crypto/sha256` (or a BLAKE3 library) when you write, keep the digest in the object's metadata with `driver.WithMetadata`, and compare after `Get`:

```go
sum := sha256.Sum256(data)
digest := hex.EncodeToString(sum[:])

_, err := t.Put(ctx, "data", "report.csv", bytes.NewReader(data),
    driver.WithMetadata(map[string]string{"sha256": digest}),
)

obj, err := t.Get(ctx, "data", "report.csv")
// ... read obj, hash it, and compare with obj.Info.Metadata["sha256"]
```

## Choosing an Algorithm

- SHA-256: widely recognized and FIPS-approved. A sensible default.
- BLAKE3: faster than SHA-256 on modern CPUs while staying cryptographic.
- XXHash: very fast but not cryptographic, so only for dedup indexes and cache keys where nobody is trying to forge a collision.
