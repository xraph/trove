This page lists the exported API of each package. Signatures come from the code; `go doc` and [pkg.go.dev](https://pkg.go.dev/github.com/xraph/trove) have the full comments.

## Core Package

**Import:** `github.com/xraph/trove`

### Constructor

```go
func Open(drv driver.Driver, opts ...Option) (*Trove, error)
```

### Object Operations

```go
func (t *Trove) Put(ctx context.Context, bucket, key string, r io.Reader, opts ...driver.PutOption) (*driver.ObjectInfo, error)
func (t *Trove) Get(ctx context.Context, bucket, key string, opts ...driver.GetOption) (*driver.ObjectReader, error)
func (t *Trove) Delete(ctx context.Context, bucket, key string, opts ...driver.DeleteOption) error
func (t *Trove) Head(ctx context.Context, bucket, key string) (*driver.ObjectInfo, error)
func (t *Trove) List(ctx context.Context, bucket string, opts ...driver.ListOption) (*driver.ObjectIterator, error)
func (t *Trove) Copy(ctx context.Context, srcBucket, srcKey, dstBucket, dstKey string, opts ...driver.CopyOption) (*driver.ObjectInfo, error)
```

An empty bucket falls back to the default bucket. `Put` and `Get` run the middleware pipeline; `Copy` calls the source driver's `Copy` directly.

### Bucket Operations

```go
func (t *Trove) CreateBucket(ctx context.Context, name string, opts ...driver.BucketOption) error
func (t *Trove) DeleteBucket(ctx context.Context, name string) error
func (t *Trove) ListBuckets(ctx context.Context) ([]driver.BucketInfo, error)
```

### Accessors

```go
func (t *Trove) Backend(name string) (*Trove, error)    // a Trove pinned to a named backend
func (t *Trove) Backends() []string
func (t *Trove) Driver() driver.Driver                  // the primary driver
func (t *Trove) DriverFor(bucket, key string) driver.Driver
func (t *Trove) Config() Config
func (t *Trove) Pool() *stream.Pool
func (t *Trove) Stream(ctx context.Context, bucket, key string, dir stream.Direction, opts ...stream.Option) (*stream.Stream, error)
func (t *Trove) Resolver() *middleware.Resolver
func (t *Trove) CAS() *cas.CAS                          // nil unless WithCAS was used
func (t *Trove) VFS(bucket ...string) *vfs.FS
```

### Lifecycle and Middleware

```go
func (t *Trove) UseMiddleware(reg middleware.Registration)
func (t *Trove) RemoveMiddleware(name string, scope middleware.Scope) // nil scope removes every registration with that name
func (t *Trove) Health(ctx context.Context) error                     // pings the primary driver
func (t *Trove) Close(ctx context.Context) error                      // closes the stream pool and every driver
```

### Config

```go
type Config struct {
    DefaultBucket     string
    ChunkSize         int64
    PoolSize          int
    ChecksumAlgorithm ChecksumAlgorithm
    StreamBufferSize  int
    Retry             RetryPolicy
}

func DefaultConfig() Config
```

`ChecksumAlgorithm` and `Retry` are stored but not applied yet: Trove neither computes checksums nor retries operations today.

### ChecksumAlgorithm

```go
type ChecksumAlgorithm int

const (
    SHA256 ChecksumAlgorithm = iota
    Blake3
    XXHash
)
```

### RetryPolicy

```go
type RetryPolicy struct {
    Strategy    RetryStrategy // RetryNone, RetryFixed, RetryExponential
    MaxAttempts int
    BaseDelay   time.Duration
    MaxDelay    time.Duration
}
```

### Option Functions

| Function | Description |
|----------|-------------|
| `WithDefaultBucket(name string)` | Default bucket for calls that pass an empty bucket |
| `WithChunkSize(size int64)` | Chunk size for streams |
| `WithPoolSize(n int)` | Maximum concurrent streams in the default pool |
| `WithPoolConfig(cfg stream.PoolConfig)` | Full pool configuration |
| `WithStreamBufferSize(size int)` | Buffer size for stream channels |
| `WithChecksumAlgorithm(alg ChecksumAlgorithm)` | Stored in the config; not applied yet |
| `WithRetry(policy RetryPolicy)` | Stored in the config; not applied yet |
| `WithBackend(name string, drv driver.Driver)` | Register a named backend |
| `WithRoute(pattern, backend string)` | Route keys matching a `filepath.Match` pattern |
| `WithRouteFunc(fn func(bucket, key string) string)` | Route with a function; `""` falls through |
| `WithVFS(bucket string)` | Default bucket for `t.VFS()` |
| `WithMiddleware(mws ...middleware.Middleware)` | Global middleware |
| `WithReadMiddleware(mws ...middleware.Middleware)` | Global, read path only |
| `WithWriteMiddleware(mws ...middleware.Middleware)` | Global, write path only |
| `WithScopedMiddleware(scope middleware.Scope, mws ...middleware.Middleware)` | Middleware limited to a scope |
| `WithScopedReadMiddleware(scope, mws...)`, `WithScopedWriteMiddleware(scope, mws...)` | Scoped, one direction |
| `WithMiddlewareAt(priority int, mws ...middleware.Middleware)` | Global middleware at a priority (lower runs first) |
| `WithCAS(alg cas.HashAlgorithm)` | Turn on content-addressable storage over the primary driver |
| `WithMetrics(r observe.Recorder)` | Record operation, scan and CAS metrics on `r`. Nil, the default, records nothing |

### Errors

```go
var (
    ErrNotFound          // parent of ErrBucketNotFound and ErrObjectNotFound
    ErrBucketNotFound
    ErrBucketExists

    ErrInvalidPath
    ErrKeyEmpty
    ErrBucketEmpty
    ErrDriverClosed      // declared; no built-in driver returns it yet
    ErrNilDriver
    ErrInvalidDSN
    ErrChecksumMismatch  // declared; nothing returns it yet
    ErrContentBlocked
    ErrStreamClosed
    ErrUploadExpired
    ErrBackendNotFound
    ErrPoolClosed
    ErrStreamNotActive

```

The not-found, exists, permission, quota and invalid-path errors are the same values as their `driver` counterparts.

**Import:** `github.com/xraph/trove/driver`

### Driver Interface

```go
type Driver interface {
    Name() string
    Open(ctx context.Context, dsn string, opts ...Option) error
    Close(ctx context.Context) error
    Ping(ctx context.Context) error

    Put(ctx context.Context, bucket, key string, r io.Reader, opts ...PutOption) (*ObjectInfo, error)
    Get(ctx context.Context, bucket, key string, opts ...GetOption) (*ObjectReader, error)
    Delete(ctx context.Context, bucket, key string, opts ...DeleteOption) error
    Head(ctx context.Context, bucket, key string) (*ObjectInfo, error)
    List(ctx context.Context, bucket string, opts ...ListOption) (*ObjectIterator, error)
```

| Package | Module | Backend | Schemes | Capabilities |
|---------|--------|---------|---------|--------------|
| `drivers/localdriver` | root | Local filesystem | `file`, `local` | Core |
| `drivers/memdriver` | root | In-memory | `mem` | Core |

Every driver has `New()` and an `Unwrap(t)` that returns the typed driver from a `*trove.Trove` (`memdriver` has `New()` only):

```go

```

## Middleware Package

**Import:** `github.com/xraph/trove/middleware`

### Direction

```go
type Direction int

const (
    DirectionRead Direction = 1 << iota
    DirectionWrite
    DirectionReadWrite = DirectionRead | DirectionWrite
)
```

### Middleware Interfaces

```go
type Middleware interface {
    Name() string
    Direction() Direction
}

type ReadMiddleware interface {
    WrapReader(ctx context.Context, r io.ReadCloser, info *driver.ObjectInfo) (io.ReadCloser, error)
}

type WriteMiddleware interface {
    WrapWriter(ctx context.Context, w io.WriteCloser, key string) (io.WriteCloser, error)
}
```

### Registration

```go
type Registration struct {
    Middleware Middleware
    Scope      Scope     // nil means ScopeGlobal
    Direction  Direction // 0 means the middleware's own Direction()
    Priority   int       // lower runs first; default 0
}
```

### Scope

Scopes are structs that implement `Scope`. The helper functions build them:

| Struct | Helper | Matches |
|--------|--------|---------|
| `ScopeGlobal{}` | none | Everything |
| `ScopeBucket{Buckets}` | `ForBuckets(buckets...)` | Named buckets |
| `ScopeKeyPattern{Patterns}` | `ForKeys(patterns...)` | Keys matching `filepath.Match` patterns |
| `ScopeContentType{Types}` | `ForContentTypes(types...)` | Intended for MIME types; today it compares the key's extension and doesn't match real content types |
| `ScopeFunc{Fn, Desc}` | `When(fn)`, `WhenDesc(desc, fn)` | A predicate over `(ctx, bucket, key)` |
| `ScopeAnd{Scopes}` | `And(scopes...)` | All children |
| `ScopeOr{Scopes}` | `Or(scopes...)` | Any child |
| `ScopeNot{Inner}` | `Not(scope)` | The inverse |

### Resolver

```go
func NewResolver() *Resolver
func (r *Resolver) Register(reg Registration)
func (r *Resolver) Remove(name string, scope Scope)
func (r *Resolver) Registrations() []Registration
func (r *Resolver) ResolveRead(ctx context.Context, bucket, key string) []ReadMiddleware
func (r *Resolver) ResolveWrite(ctx context.Context, bucket, key string) []WriteMiddleware
```

Both resolve methods sort by priority, then registration order, and cache the result per bucket and key.

## Stream Package

**Import:** `github.com/xraph/trove/stream`

A stream carries chunks between a producer and a consumer. It doesn't read from or write to a driver by itself.

## Observe Package

**Import:** `github.com/xraph/trove/observe`

The metrics Trove records and the interface it records them on. It imports only the standard library.

```go
type Recorder interface {
	Add(name string, delta float64, labelValues ...string)     // counters
	Observe(name string, value float64, labelValues ...string) // histograms
}

type Metric struct {
	Name    string
	Kind    Kind // KindCounter or KindHistogram
	Help    string
	Unit    string // "s", "By" or ""
	Labels  []string
	Buckets []float64
}

func Metrics() []Metric // every metric, as fresh copies
```

The package also exports the metric names (`MetricOperationDuration` and the rest), the label keys and every label value as constants. A Recorder gets label values in the order the metric declares its keys, must be safe for concurrent use, and should ignore a name it doesn't know. The [observability page](/docs/integration/observability) lists the metrics and spans.

## Extension Package

**Import:** `github.com/xraph/trove/extension` (its own module)


| Option | Description |
|--------|-------------|
| `WithConfig(cfg Config)` | Set the whole configuration |
