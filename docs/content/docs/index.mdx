Trove is a multi-backend object storage library for Go. You write against one API (`Put`, `Get`, `List`, `Copy`, buckets) and pick the backend when you start up, so the same code runs on local disk in development and on S3 in production.

Trove supports these backends through dedicated drivers:

- Local filesystem: files on disk with sidecar `.meta.json` metadata
- In-memory: ephemeral storage for tests
- Amazon S3: AWS and S3-compatible stores such as MinIO and R2
- Google Cloud Storage: GCS, with compose-based multipart uploads
- Azure Blob: block blob storage with SAS-signed links and staged multipart uploads
- SFTP: remote files over SSH, with one directory per bucket

## Key Features

- Unified storage API: the same `Put`, `Get`, `Delete`, `Head`, `List` and `Copy` on every backend
- Composable middleware: compression (zstd), encryption (AES-256-GCM), duplicate detection, virus scanning (ClamAV) and watermarking, scoped to buckets or keys
- Streaming engine: chunked transfers with backpressure, pause and resume, progress hooks and stream pools
- Content-addressable storage: store by SHA-256, BLAKE3 or XXHash hash, with reference counts and pinning
- Virtual filesystem: a directory-shaped view of a bucket, with an `io/fs.FS` adapter
- Multi-backend routing: glob patterns and functions that send keys to named backends
- Capability interfaces: multipart uploads, presigned URLs and range reads on the S3, GCS and Azure drivers
- Forge integration: an extension that opens drivers from DSNs, provides `*trove.Trove` through DI and keeps metadata in Grove

## Quick Example

```go
// Create and open the driver, then pass it to Trove
drv := localdriver.New()
if err := drv.Open(ctx, "file:///tmp/storage"); err != nil {
    log.Fatal(err)
}

t, err := trove.Open(drv,
    trove.WithDefaultBucket("uploads"),
    trove.WithMiddleware(encrypt.New(encrypt.WithKeyProvider(kp))),
)
if err != nil {
    log.Fatal(err)
}
defer t.Close(ctx)

// Store and retrieve objects
_, err = t.Put(ctx, "uploads", "photo.jpg", reader)
obj, err := t.Get(ctx, "uploads", "photo.jpg")
defer obj.Close()
```
